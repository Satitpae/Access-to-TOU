# Access to TOU

แปลง Access datalog เป็นไฟล์ TOU รายเดือนสำหรับ Dashboard_TOU

[ทดลองหน้าเว็บด้วยข้อมูลจำลอง](https://satitpae.github.io/Access-to-TOU/)

## ใช้กับไฟล์จริงบน Windows

1. ใช้ PowerShell 7 และ Microsoft Access Database Engine ที่มี bitness ตรงกัน
2. กด **Code → Download ZIP** แล้วแตกไฟล์
3. ดับเบิลคลิก `Open-AccessToTOU.cmd` แล้วเลือก `.mdb` หรือ `.accdb`
4. ติ๊กเดือนในหน้าเว็บ กด **Export .tou** แล้วดาวน์โหลด

อ่านตาราง `Data Log # 1` และดึงรหัสฐาน 16 จากต้นชื่อไฟล์ เช่น `D18_` เพื่อสร้างชื่อ `D18Nov26.tou` การแปลงไฟล์จริงทำบนเครื่อง หน้า HTML ชั่วคราวมีข้อมูลที่ใช้สร้างไฟล์ดาวน์โหลด

## ซ่อมข้อมูลในไฟล์ TOU เดิม

1. เปิด `Open-TOU-Repair.cmd` บน Windows ที่มี PowerShell 7 และ Access Database Engine
2. เลือกโฟลเดอร์ Access กับ TOU แล้วกด **จำโฟลเดอร์และสแกน** โปรแกรมจับคู่ตามรหัสมิเตอร์ที่ต้นชื่อไฟล์และใช้โฟลเดอร์เดิมได้ในครั้งถัดไป
3. เลือกรายการช่วงขาดเพื่อดูตารางและกราฟ kWh สะสมทีละวัน
4. เลือกไฟล์ที่ต้องการด้วย Ctrl หรือ Shift แล้วกด **เติมช่วงที่ผ่านในไฟล์ที่เลือก** โปรแกรมตรวจไฟล์ซ้ำและสร้างไฟล์สำรอง `.bak` ก่อนเก็บผล

รุ่นนี้รองรับช่องว่างกลางไฟล์ที่ kW และ kWh เป็นศูนย์ทั้งคู่ โดยต้องมีค่าอ้างอิงก่อนและหลังช่วงขาด ค่า kWh ของ Access ต้องตรงกับ TOU ที่ขอบทั้งสองด้านภายใน 0.001 kWh และเวลาเทียบได้แบบเดียวในช่วง ±15 นาที ข้อมูล Access ต้องครบทุกช่องและยอดสะสมต้องไม่ลดลง ช่องหลังค่าล่าสุด ช่องข้ามเดือน และช่องที่ไม่มีจุดอ้างอิงต้องตรวจแยกด้วยตนเอง

ทดสอบด้วยข้อมูลจำลองโดยรัน `pwsh -NoProfile -File ./Test-TouRepair.ps1`
